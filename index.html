🧱 Primeiros passos com HTML

HTML é a linguagem de marcação utilizada para estruturar o conteúdo de páginas da web. 

<h1>Meu primeiro blog</h1>
<p>Olá! Este é meu primeiro texto.</p>

🎨 Personalizando com CSS

CSS permite definir cores, tamanhos, espaçamentos e a aparência dos elementos. 

body {
    background-color: #102D49;
    color: white;
}

⚡ Dando vida com JavaScript

JavaScript permite responder às ações dos visitantes e modificar elementos da página. 

function mostrarMensagem() {
    alert("Bem-vindo ao meu blog!");
}
